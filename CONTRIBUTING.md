# Contributing to HotDang

Thanks for helping people find hotdogs.

## Got an idea?

Open an issue with the **Idea** template. Say what you'd like and why it would help hotdog hunters.

## Found a bug?

Open an issue with the **Bug** template. Include what you did, what you expected, and what happened.

## Want to write code?

1. Fork the repo and create a branch.
2. Make your change. Keep each pull request to one thing.
3. Open `index.html` in a browser and check that it still works on phone and desktop widths, in both light and dark mode.
4. Open a pull request that describes the change, with a screenshot if it changes how the app looks.

## How changes get merged

The project owner reviews every pull request. Nothing is merged without their approval.

## Be kind

Be friendly and constructive. Harassment or abuse gets you removed from the project.
